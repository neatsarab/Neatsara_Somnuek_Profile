# Neatsara Somnuek · UX/UI Portfolio

Personal portfolio website of **Neatsara Somnuek (เณศรา สมนึก)**, UX/UI Designer.

- Case studies, delivered work, company products and bid projects

A static site: open `index.html`, or deploy the folder as-is to any static host (Netlify, GitHub Pages).
